# 项目启动流程

## 1. 环境准备
确保已安装 Python 3.8+。
可以在终端输入 `python --version` 检查。

## 2. 安装依赖
在项目根目录下（`keywordAggregation` 目录），运行以下命令安装所需库：
```bash
pip install -r backend/requirements.txt
```

## 3. 启动后端服务
在项目根目录下，运行：
```bash
python backend/main.py
```

## 4. 验证运行
服务启动后，会自动打开浏览器访问接口文档页面：
- 地址：http://127.0.0.1:8000/docs
- 你可以在该页面测试 API 接口。

## 5. 目录结构说明
- `backend/main.py`: 后端入口文件
- `backend/requirements.txt`: 项目依赖列表
